Vercel 배포 & GEMINI_API_KEY 보안 가이드

요청하신 서버리스 함수 api/generate.js 완벽 연동

💡 왜 서버리스 함수(api/generate.js)로 분리해야 할까요? 클라이언트(index.html)에 Gemini API Key를 직접 입력해 배포하면 브라우저 개발자 도구(F12)에서 키가 그대로 노출됩니다. 따라서 백엔드 서버리스 함수에서 process.env.GEMINI_API_KEY로 안전하게 읽어와 호출하는 것이 정석입니다!

📄 1. api/generate.js (서버리스 함수 코드) 

export default async function handler(req, res) {
  // CORS & Method Check
  if (req.method !== 'POST') {
    return res.status(405).json({ error: 'Method Not Allowed' });
  }

  // Vercel 환경변수에서 API 키 추출
  const apiKey = process.env.GEMINI_API_KEY;
  if (!apiKey) {
    return res.status(500).json({ error: '서버에 GEMINI_API_KEY가 설정되지 않았습니다.' });
  }

  try {
    const { prompt, systemInstruction } = req.body;

    const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent?key=${apiKey}`;

    const payload = {
      contents: [{ parts: [{ text: prompt }] }],
      systemInstruction: {
        parts: [{ text: systemInstruction }]
      }
    };

    const response = await fetch(apiUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload)
    });

    if (!response.ok) {
      const errText = await response.text();
      return res.status(response.status).json({ error: errText });
    }

    const data = await response.json();
    return res.status(200).json(data);
  } catch (error) {
    return res.status(500).json({ error: error.message || 'Internal Server Error' });
  }
}

🚀 Vercel 배포 3단계

  1. GitHub 레포지토리에 위 구조대로 업로드합니다.
  2. Vercel 대시보드에서 Add New Project로 레포지토리를 불러옵니다.
  3. Project Settings의 Environment Variables에 GEMINI_API_KEY를 등록하고 Deploy 버튼을 누르면 끝!
